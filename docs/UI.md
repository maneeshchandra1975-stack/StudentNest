## Design System

### Color Palette
| Token | Hex | Usage |
|---|---|---|
| Primary | `#10b981` | Emerald — CTAs, active states |
| Primary Dark | `#059669` | Hover states |
| Background | `#020617` | Slate-950 — main background |
| Surface | `#0f172a` | Slate-900 — cards, panels |
| Surface-2 | `#1e293b` | Slate-800 — inputs, borders |
| Text Primary | `#f8fafc` | Slate-50 |
| Text Secondary | `#94a3b8` | Slate-400 |
| Danger | `#ef4444` | Errors, destructive actions |
| Warning | `#f59e0b` | Amber — alerts |

### Typography
| Role | Font | Size |
|---|---|---|
| Headings | Inter | 2xl–5xl |
| Body | Inter | base (16px) |
| Code | JetBrains Mono | sm |

### Spacing Scale
Follows Tailwind's default 4px-base scale.

### Border Radius
- Small components: `rounded-lg` (8px)
- Cards: `rounded-2xl` (16px)
- Buttons: `rounded-xl` (12px)
